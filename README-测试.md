# 《续禾杀》联机测试说明（Windows）

测试服务器在你自己的电脑上运行，再用 Cloudflare 的免费临时隧道生成一个公网地址，朋友打开这个地址就能和你对战。全程免费，不用注册账号，也不用买服务器。

## 一、第一次准备（只做一次）

1. **安装 Node.js**
   打开 https://nodejs.org ，下载 **LTS** 版（绿色按钮，版本号 22.18 或更新都行），双击安装，一路点「下一步」。
   装完后按 `Win + R`，输入 `cmd` 回车，再输入 `node -v` 回车。显示 `v24.x.x` 或 `v22.18` 以上的版本号就说明装好了。
2. **解压测试包**
   把 `xuhesha-test.zip` 解压到一个**路径里没有空格**的文件夹，比如 `D:\xuhesha-test`。不要直接在压缩包里双击运行。

## 二、每次开服

1. 双击 `share.bat`。
2. 第一次运行时会自动下载 cloudflared（大约 50 MB），并安装服务器依赖（npm install），需要等 1～3 分钟。以后再开就很快了。
3. 看到黄色框里的地址（形如 `https://xxxx-xxxx-xxxx.trycloudflare.com`），就说明好了。地址已经复制到剪贴板。
4. **把地址发给朋友**（微信或 QQ 直接粘贴）。你自己也用浏览器打开同一个地址。
5. 一个人点「建房」，会得到 6 位房间号，另一个人输入房间号加入，就能开打。

注意事项：
- **黑色窗口不能关**。窗口关了、电脑睡眠或关机，游戏都会断。玩完以后直接关掉窗口就行。
- 每次开服的地址都**不一样**，每次都要重新发给朋友。
- 地址刚出来时，可能要等 10～20 秒才能打开。

## 三、常见问题

**弹出「Windows 安全中心 / 防火墙」窗口**
点「允许访问」就行，只勾「专用网络」也可以。服务器只在本机监听，所有外部连接都经过 cloudflared，不会对局域网开放端口。

**双击 share.bat 后窗口一闪就没了，或者提示「无法加载脚本」**
在解压后的文件夹地址栏输入 `powershell` 回车，然后输入 `.\share.bat` 运行，就能看到具体报错。如果被杀毒软件拦了，把这个文件夹加进信任区。

**提示「没找到 Node.js」**
Node.js 没装好，或者装完没有重新打开窗口。装好以后关掉旧窗口，重新双击 `share.bat`。

**提示「Node.js 版本太旧」**
去 https://nodejs.org 装最新的 LTS 版，它会覆盖旧版本。

**npm install 很慢或者失败**
在 cmd 里运行 `npm config set registry https://registry.npmmirror.com`，换成国内镜像，然后删掉 `server\node_modules` 文件夹（如果有的话），再双击 `share.bat`。

**cloudflared 下载失败**
GitHub 在国内有时连不上。可以手动下载 https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe ，改名为 `cloudflared.exe`，放进包里的 `tools` 文件夹（没有就新建一个），再双击 `share.bat`。

**一直不出地址，提示「隧道没起来」**
有些网络（特别是校园网和公司网）会挡掉 cloudflared 用的 7844 端口或 UDP。可以：
1. 换一种连接方式：在文件夹地址栏输入 `cmd` 回车，运行 `set CF_PROTOCOL=http2 && share.bat`；
2. 还不行的话，换手机热点再试。

**地址打不开（显示 530、1033 或者一直转圈）**
- 刚出来的地址要等 10～20 秒，刷新一下就行。
- 确认黑色窗口还开着，电脑没有睡眠。
- 地址是这一次开服的吗？旧地址每次重开都会失效。
- 朋友那边打不开，你这边能打开：让朋友换个浏览器或者关掉代理/VPN 再试。

**能打开网页，但连不上房间或者经常掉线**
刷新页面。掉线 1 分钟内回来，可以接着打；超过 1 分钟就判负。如果频繁掉线，多半是隧道所在的网络不稳定，可以换网络或者换 `CF_PROTOCOL=http2` 试试。

**想看本机测试（不开隧道）**
浏览器打开 http://127.0.0.1:8787/ ，开两个标签页就能自己和自己打。

## 四、对局记录（帮我们调平衡）

每打完一局，服务器会在 `server\data\games.jsonl` 里记一行：谁先手、谁赢、打了几回合、怎么结束的（打到分出胜负、掉线、认输）、用了多久。只记这些，不记名字和聊天。
测试一段时间后，把这个文件发给项目组就行。想自己看统计，可以在 `server` 文件夹的地址栏输入 `cmd` 回车，运行 `node src/stats.ts`。
